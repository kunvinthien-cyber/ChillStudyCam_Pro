## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### API Configuration

Local development uses the Vite `/api` proxy to `http://127.0.0.1:8000`, avoiding browser CORS and `localhost` IPv6 resolution issues. For a production deployment, set the Vercel environment variable `VITE_API_BASE_URL` to the backend URL including `/api` (for example, `https://your-backend.example/api`) before building. Set `FRONTEND_URL` on the backend to the deployed frontend origin so Laravel CORS allows requests from it.

### Run Unit Tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```

### Run End-to-End Tests with [Playwright](https://playwright.dev)

```sh
# Install browsers for the first run
npx playwright install

# When testing on CI, must build the project first
npm run build

# Runs the end-to-end tests
npm run test:e2e
# Runs the tests only on Chromium
npm run test:e2e -- --project=chromium
# Runs the tests of a specific file
npm run test:e2e -- tests/example.spec.ts
# Runs the tests in debug mode
npm run test:e2e -- --debug
```
